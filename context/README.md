# Context folder

Human- and agent-readable project context. Cursor rules in `.cursor/rules/` point here.

| File | Purpose |
|------|---------|
| `agent-guidelines.md` | How agents should implement work |
| `git-workflow.md` | Branch + PR workflow (required) |
| `code-review.md` | Review checklist before merge |
| `architecture.md` | System diagram and data flow |
| `phases/current.md` | What phase you are on (update as you learn) |
| `decisions/` | ADR-style notes (optional, one file per decision) |
| `notes/` | Scratchpad (optional) |

**Start here:** `agent-guidelines.md` + `git-workflow.md` + `code-review.md`.
